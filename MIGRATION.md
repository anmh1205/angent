# Migration: Cogent 16 → ANGENT 17

ANGENT is a semantic redesign, not a search-and-replace rename.

| Cogent 16 | ANGENT 17 | Change |
|---|---|---|
| cogent | angent | Root remains router only |
| cogent-contract | angent-contract | stronger task/success model |
| cogent-context | angent-context | authoritative state reconstruction |
| — | angent-reasoning | new cognitive core |
| cogent-research | angent-research | evidence targeting around uncertainty |
| cogent-chat-work | angent-execution | execution becomes actuator + observer |
| cogent-quality | angent-quality | solution integrity + communication integrity |
| cogent-feedback + cogent-distill | angent-learning | experience → understanding → promotion |
| cogent-checkpoint | angent-continuity | durable continuation semantics |
| cogent-authoring | angent-authoring | retained integrated authoring ownership |
| cogent-format | angent-format | destination fidelity |
| cogent-shell | angent-shell | ANGENT signature |

Legacy Cogent feedback evidence and useful authoring references are migrated as evidence/reference material, not blindly copied into production rules.
