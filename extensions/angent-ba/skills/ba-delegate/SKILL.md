# Delegate only a bounded BA specialist task

## Purpose

Delegate when parallel evidence collection, independent review, distinct provider rights or isolation demonstrably improves the result. Do not construct imaginary background workers, fake messages to another model or a shadow orchestration engine. ANGENT Root selects whether real delegation is useful and Execution verifies that an actual delegation tool exists.

## Prepare a handoff

State one concrete deliverable and its audience. Include a bounded dataset (document links, source commit and relevant excerpts), stable feature and artifact IDs, constraints, which outputs may be proposed, which effects are forbidden, and acceptance criteria. State what remains unsettled and how evidence should be cited. Never forward entire conversation history or secrets by default.

## Example independent-review job

'Review FR-AUTH-001 through FR-AUTH-012 and BR-AUTH-003 at SRS revision 4. Find authorization leaks, business-rule contradictions, missing error transitions and untestable statements. Return a table of source-linked findings with severity rationale; do not edit Jira, source code or SRS. Identify sources not inspected.'

## Execution and reconciliation

1. Observe the host's actual worker/tool capabilities. If no delegation is available, perform sequential in-context review rather than claiming concurrency.
2. Grant minimal permissions and a read-only baseline for reviewer roles. Keep tool access and persisted state under ANGENT Execution.
3. Receive evidence, compare to originals and discard unsupported opinions. Re-run critical checks with a separate path if the review materially affects risk.
4. Merge relevant findings into Root's answer and report what was independently verified. Never promote unreviewed worker output to accepted specification.
5. If the worker fails or loses context, preserve the unmet acceptance criteria and re-route to the safest available method.

## Acceptance

Real worker invocation and result are observable when claiming delegation. A reviewer's completion cannot replace the user's approvals or ANGENT Quality gate.


## Ownership

ANGENT Root/Core retains reasoning, stakeholder intent, source authority and final Quality. This method is a task-specific support skill and does not create a second runtime, memory system or autonomous scheduler.
