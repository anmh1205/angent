# R19: ANGENT root authority and specialist cooperation

## Operational contract

ANGENT Root owns interpretation, task continuity, final reasoning and response; extensions own scoped specialist methods. Hub is a semantic registry, not an independent supervisor or stateful workflow engine.

## Checks before accepting an artifact

Use the fewest specialist methods that add actual value. A BA kit may recommend Figma, Jira, Confluence or a second agent but cannot invoke uninstalled tools, grant external write permission or declare task completion.

## Failure response

Distinguish source method from execution evidence. Keep local and ChatGPT packaging honest: one discoverable OpenAI root Skill; projected specialist Skills elsewhere do not guarantee host routing precedence.

## Grounded example

An automatically selected `ba-jira` procedure cannot change issues before ANGENT Execution verifies user authority, real provider target and successful read-back.

**Evidence boundary:** specialist advice does not establish completed provider writes or approve business requirements. The actual source and observed result remain decisive; ANGENT Root and Quality retain oversight.
