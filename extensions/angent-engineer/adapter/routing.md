# Engineer Kit Adapter

Expose engineering **specialist methods**, not a second cognitive layer or an independent AgentKit supervisor. The manifest maps `code.review`, `code.debug`, `software.test`, `software.implementation`, `product.ux` and related capabilities to maintained `ak-*` Skills. Core retains intent, execution permissions, verification and final synthesis.

Use official AgentKit Engineer only if native invocation is established in the live host. Otherwise use the maintained portable Skill fallback. These are exclusive routes for one engineering task. Preserve portable role semantics even when the host cannot create concurrent agents; do not counterfeit a Team lifecycle or native CLI result. `ak-explain` remains in source for parity but is not exposed; Core Reasoning and Authoring own ordinary explanation.

For fine-grained native selection details consult `skills/angent-execution/references/engineer-selection.md` and `skills/ak-agentkit/references/routing-protocol.md`. On a packaged gateway these methods are under `skills/angent/references/catalog/`.
