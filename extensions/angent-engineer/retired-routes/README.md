# Retired Engineer Skill routes

These names are **not public fallback Skills**. They are preserved only as compatibility/navigation notes for users or old artifacts that mention a retired upstream invocation.

| Retired identity | Current route |
|---|---|
| `ak-security-scan` | `ak-security` for defensive scan/audit/fix reasoning |
| `ak-use-mcp` | use MCP tools already exposed by the runtime; use `ak-mcp-builder` to build a server, `ak-webmcp` for in-browser page tools, or `ak-agent-browser` for browser automation |
| `ak-handover` | `ak-handoff` |
| `ak-html-video` | `ak-hyperframes` or `ak-media-processing` depending the requested artifact |
| `ak-sequential-thinking` | `ak-fable-thinking` for structured problem reasoning |
| `ak-web-design-guidelines` | `ak-ui-ux-pro-max` for broad UI/UX guidance; `ak-frontend-design` when the outcome is an implemented interface |

Do not expose these retired names under the plugin `skills/` discovery root.

A compatibility route is not a runnable identity and does not create authority for the replacement workflow.
