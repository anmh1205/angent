# Modality routing

- image/photo/UI → vision;
- image generation/edit → image generation;
- speech/audio → transcription/audio analysis;
- video → video/frame/timestamp analysis;
- PDF/document → document/PDF extraction first;
- scanned/image-only document → OCR only when needed.

Use conversion only when the destination tool requires it.

Preserve quality/resolution/aspect ratio needed for the task.
