# Context lifecycle

## Stable project instruction

Store durable repository conventions and architecture maps in AGENTS.md.

## Active work

Store unfinished-task frontier in ANGENT Continuity.

## Long-term dynamic knowledge

Store user/project memory with topic, scope, provenance and synthesis/update semantics.

## Historical evidence

Keep raw session/journal history searchable but out of the default prompt.

## Specialist isolation

Give a specialist only the task, scope, constraints and evidence it needs.

## Compaction

Before/at meaningful context boundaries preserve:
- current objective;
- verified progress;
- decisions;
- unresolved uncertainty;
- artifact/source pointers;
- next safe action.

Compaction is lossy by design; source pointers preserve recoverability.
