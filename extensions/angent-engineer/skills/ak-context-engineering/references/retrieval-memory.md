# Retrieval and memory

Memory categories should remain scoped:
- user/global preference/context;
- project knowledge;
- promoted Learning mechanisms;
- active task state in Continuity.

Retrieve only what can change the current task.

When new information overlaps a memory topic, synthesize/update/supersede rather than append another sentence.

Use raw history as retrievable evidence, not default prompt context.

Preserve provenance for facts likely to become stale or contested.
