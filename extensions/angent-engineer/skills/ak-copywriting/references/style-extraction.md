# Writing-style extraction

Use when the user supplies examples or an established brand voice.

Extract characteristics rather than copying sentences:

- sentence length/rhythm;
- formality;
- directness;
- vocabulary/register;
- technical vs emotional emphasis;
- humor/restraint;
- headline patterns;
- CTA style;
- punctuation/formatting habits;
- phrases/tropes to avoid.

Separate **voice** from content facts.

The new copy must still reflect the current offer/audience/evidence.

Do not imitate protected text by reproducing distinctive passages; learn higher-level style characteristics.
