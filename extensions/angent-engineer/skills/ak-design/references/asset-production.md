# Visual asset production

Before production identify:
- physical/digital medium;
- exact dimensions/aspect ratio;
- safe areas/bleed when print;
- output formats;
- text that must remain editable;
- accessibility/legibility constraints.

## Posters/banners/social

Prioritize:
1. one clear focal message;
2. hierarchy that survives thumbnail view;
3. sufficient contrast;
4. realistic copy length;
5. export quality appropriate to medium.

## Generated imagery

When AI-generated imagery is used:
- verify text/logo artifacts;
- avoid accidental trademark/copyright confusion;
- keep brand-critical typography/logos as controlled design elements when possible;
- preserve source prompts/edits only when useful for reproducibility.

Inspect the final exported artifact, not only the design canvas.
