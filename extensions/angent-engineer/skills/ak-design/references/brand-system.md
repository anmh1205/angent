# Brand system

A brand system is a set of repeatable visual decisions tied to a communication objective.

## Define

- brand idea / desired perception;
- primary audiences;
- core use cases;
- typography hierarchy;
- color roles rather than random palette;
- shape/icon/image language;
- layout/grid behavior;
- motion principles when needed.

## Logo/mark work

Test:
- small-size recognition;
- monochrome use;
- light/dark backgrounds;
- horizontal/stacked lockups when relevant;
- icon-only/product use;
- reproduction in print and low-resolution contexts.

Avoid forcing initials/letters into every concept when the brand can be expressed more coherently another way.

## Tokens

Document reusable tokens only when multiple assets need consistency.

Do not create dozens of token names before the actual visual system has proven itself.
