# Design deliverable routing

## Logo / mark

Focus on concept, recognizability, reproduction, monochrome/small-size behavior, required lockups and vector/editability.

## Corporate / brand identity

Extend an accepted visual idea into typography, semantic color roles, grid, imagery, iconography, tone and representative applications.

## Banner / social asset

Optimize hierarchy for the exact aspect ratio, platform placement and thumbnail/viewing distance. Recheck current platform dimensions when freshness matters.

## Poster

Prioritize one communication hierarchy, physical/digital production constraints, text accuracy and legibility.

## Icon

Design for the actual size/system. Test silhouette, optical alignment, SVG/viewBox/scalability and currentColor/accessibility behavior when used in UI.

## Slides / visual presentation

Treat slides as a sequence of visual arguments with recurring layout/typography logic. Use the presentation capability for an editable deck.

## Campaign package

Define the shared visual system once, then adapt hierarchy/composition across channels rather than forcing identical layouts.

## Generator/data boundary

The pinned upstream package includes specialized datasets/scripts for several deliverables.

The fallback does not claim those engines. Use available image/vector/presentation tooling and current authoritative platform specs while preserving the workflow above.

Choose the smallest workflow matching the requested deliverable.
