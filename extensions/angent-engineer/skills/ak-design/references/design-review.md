# Design review

Review against the communication objective and real medium, not personal taste or checklist completion.

## Concept

Ask:
- Is there a coherent visual idea, not merely a style treatment?
- Would the artifact still feel specific to this brand/topic if the name/logo were hidden?
- Are decorative elements doing communicative work?
- Are variations conceptually different or just cosmetic?

A weak concept is not fixed by adding more polish. Conversely, do not discard an accepted strong symbol because one export has uneven strokes, mismatched alignment or a poor color: repair the optical/production defect while protecting the agreed concept. Compare at equivalent size and background before attributing quality differences to the wrong cause.

## Craft

Inspect:
- hierarchy and focal order;
- alignment/grid and spacing rhythm;
- typography fit/readability;
- color roles/contrast;
- image/icon consistency;
- composition balance and intentional tension;
- distinctiveness without novelty-for-its-own-sake.

## Production

Verify:
- exact dimensions/aspect;
- safe area/bleed/DPI/color mode when physical production requires them;
- text accuracy;
- logos/trademarks;
- clipping/overflow/fallback fonts;
- target-size legibility;
- export format/vector validity.

## System coherence

When the scope is a brand/campaign system:
- repeated rules should be reproducible;
- channel adaptations should remain recognizably related;
- exceptions should be purposeful.

Prefer a few causal findings over many subjective nits.

Inspect the final exported artifact, not only the source file.
