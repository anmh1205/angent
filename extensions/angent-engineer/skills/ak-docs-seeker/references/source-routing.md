# Documentation source routing

Prefer, by claim:
- official API/reference docs;
- normative standard/schema;
- canonical repository/source;
- release notes/changelog;
- locally installed source/version;
- high-quality third-party explanation;
- community discussion for operational experience.

For rapidly changing libraries, verify publication/release version.

A search-result snippet is discovery evidence, not the final authority when the underlying source is available.
