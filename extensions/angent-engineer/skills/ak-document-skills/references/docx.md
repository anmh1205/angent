# DOCX

Use for editable long-form documents, reports, proposals and structured text.

## Preserve

- heading hierarchy;
- paragraph/list semantics;
- tables;
- captions/references;
- page/section breaks;
- headers/footers where required;
- links and footnotes/endnotes when relevant.

## Quality

Use styles instead of ad-hoc formatting when possible.

Avoid manual spaces/tabs for layout.

After generation inspect page breaks, orphan headings, table overflow and image placement.

For large rewrites, preserve document-level terminology and section relationships, not only local formatting.
