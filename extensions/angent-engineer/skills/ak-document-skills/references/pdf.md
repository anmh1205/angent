# PDF

PDF is a rendered/fixed-layout destination.

## Creation

Verify:
- page size/margins;
- font embedding/substitution;
- images and vector graphics;
- links/bookmarks;
- page numbers;
- code/table clipping;
- metadata when required.

## Inspection

Prefer extracted text/structure when available.

Use page screenshots/rendering for layout/visual checks.

OCR is a last resort for image-only pages.

A valid PDF file is not enough; verify the actual pages relevant to the task.
