# Slides

A presentation is a sequence of visual arguments, not a document split into pages.

## Build

- define audience and decision/story;
- one main point per slide;
- choose visual representation before filling text;
- preserve consistent layout hierarchy;
- keep tables/charts readable at presentation distance;
- use speaker notes only when useful.

## Verification

Render slides and inspect:
- clipping/overflow;
- contrast;
- visual consistency;
- chart/table readability;
- awkward title/body wrapping;
- sequence/story coherence.

Avoid dense paragraphs that require reading instead of presenting.
