# Spreadsheets

A workbook combines data, calculations and presentation.

## Preserve

- typed data;
- formulas;
- named ranges/tables when useful;
- validation;
- filters/sorts;
- chart source ranges;
- sheet relationships.

## Quality

Prefer formulas over manually copied computed values when the workbook must update.

Check formula errors, blank/misaligned ranges, date/number formats and totals.

Charts should answer a real question and use the correct axis/category structure.

Do not use document/PDF tooling to edit spreadsheets.
