# High-rigor reasoning moves

## 1. Frame

Identify:
- literal request;
- desired end-state;
- deliverable type;
- scope/non-scope;
- load-bearing facts.

Do not silently replace the user's goal with a different “better” goal.

## 2. Ground

Verify facts that would collapse the answer if wrong.

Prefer direct observation/reproduction/primary source over memory when available cheaply.

Treat version-sensitive behavior as stale until checked.

## 3. Reason

Build mechanism.

Use competing hypotheses when they predict different observations.

Choose the next check for discrimination, not confirmation.

Simulate concrete inputs/states.

For changes, track:
- preserved invariants;
- deliberate breaks/migrations;
- risks/watchpoints.

## 4. Attack

Find the strongest counterexample or failure path.

Ask what observation would prove the conclusion wrong.

Run cheap kill-tests when available.

## 5. Deliver

Lead with the outcome/answer.

Then provide decisive evidence and necessary reasoning.

State the weakest unresolved point rather than hiding it.

Calibration and clarity matter more than displaying effort.
