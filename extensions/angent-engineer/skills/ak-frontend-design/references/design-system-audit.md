# Design-system audit

Extract:
- page shell/navigation;
- grid/container widths;
- spacing scale;
- typography scale;
- color roles;
- surface/elevation;
- radius/border;
- component variants;
- icon language;
- density;
- form/table/chart patterns.

Look for reuse opportunities before creating new components.

A real design system is visible in repeated decisions, not just a token file.
