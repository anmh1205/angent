# Reference replication

When learning from a template/live product:

1. identify the design grammar;
2. map reference components to local product needs;
3. preserve strong layout/state patterns;
4. adapt content/data/branding;
5. avoid copying irrelevant page structure;
6. compare rendered local result side by side.

The goal is to reuse **quality mechanisms**, not create a loose visual resemblance.

When source/template licensing matters, respect its terms.
