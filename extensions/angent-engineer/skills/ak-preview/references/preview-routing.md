# Preview routing

Examples:
- Markdown → Markdown/HTML reader;
- HTML/web app → browser;
- Mermaid/diagram source → renderer;
- DOCX/PDF/PPTX → format renderer;
- spreadsheet → workbook/table/chart view;
- image/video → media viewer.

Use a generated explanation/diagram only when the source artifact cannot communicate the relation the user needs to inspect.
