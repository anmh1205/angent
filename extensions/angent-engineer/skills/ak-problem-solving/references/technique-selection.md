# Technique selection

Use:
- **inversion** when one assumption constrains all options;
- **simplification cascade** when fixes add growing special cases;
- **boundary reframe** when local changes cannot explain the outcome;
- **extreme-scale test** when behavior under scale is uncertain;
- **counterexample** when a rule/claim may be too broad;
- **analogy/transfer** when another domain has the same mechanism;
- **decomposition by ownership/state flow** when a large problem is poorly partitioned.

A technique is successful when it changes the useful model, not when the checklist was completed.
