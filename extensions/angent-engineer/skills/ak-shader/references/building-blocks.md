# Shader building blocks

## Coordinates

Know whether calculations use:
- UV 0–1;
- centered normalized coordinates;
- screen pixels;
- world/view space.

## Shapes

SDFs are useful when shape distance enables smooth edges, outlines or boolean composition.

## Noise

Choose value/gradient/simplex/cellular/fBm based on the desired structure and cost.

## Color

Keep color-space assumptions explicit.

Use palettes/gradients intentionally rather than stacking arbitrary sinusoidal colors.
