# Discovery metadata

Metadata must help the runtime decide **when this capability applies**.

Description should include:
- task/outcome;
- strong trigger phrases or situations;
- exclusions when confusion is likely.

Avoid:
- vague “helpful general assistant” descriptions;
- implementation-only details;
- huge lists of unrelated keywords.

A Skill that activates too often creates context pollution; one that is too narrow becomes undiscoverable.
