# Theming and accessibility

Use semantic color roles such as background, surface, text, muted, border, primary, destructive—not only raw color names.

Verify:
- text/background contrast;
- focus visibility;
- disabled state distinguishability;
- hover not being the only affordance;
- dark/light parity;
- reduced motion where relevant;
- zoom/reflow/content overflow.

Do not sacrifice readable contrast for brand color purity.
