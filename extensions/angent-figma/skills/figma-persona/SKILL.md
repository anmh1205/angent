# figma-persona: Synthesize research-backed behavior patterns without stereotypes

## Applicability and context

Use this specialist when a requested Figma deliverable needs **synthesize research-backed behavior patterns without stereotypes**. Gather only the context that changes the output: authorized research notes, segment boundaries and observed needs. Preserve project-approved semantics and styles. ANGENT Root retains task intent, user authority, tool selection, reasoning, and completion checks.

## Diagram/design method

Separate direct quotes and inferences; choose goals, contexts, constraints, assistive needs; mark sampling limits and contradictory evidence. Model semantic entities and relationships **before** canvas geometry. Prefer stable node/edge identifiers and update-in-place semantics where the actual native tool supports them. Work on only the approved document/selection; preserve existing user edits and component identity.

## Target deliverable

Produce **persona card with references, limitations and hypotheses**. If live Figma tools are available and permission confirmed, create or edit actual editable objects and read back the changed target state. Otherwise provide a structured model and clear unsupported-operations section rather than pretending to have made canvas changes.

## Review gate

- No imaginary demographics or false customer interviews.
- Check role ownership, meaningful labels, accessible names, off-canvas/clipped nodes, edges without endpoints, rendering clarity and contradiction with accepted BA requirements where applicable.
- Distinguish structural validation from rendered visual QA; inspect native Figma result if tool exists.
