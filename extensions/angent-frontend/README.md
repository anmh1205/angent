# ANGENT Frontend — visual-design extension

A task-specific, optional frontend art-direction capability under ANGENT Root. Maintained source lives in `skills/angent-frontend-design/` and its references. The extension does **not** install an independent plugin or claim its own authority.

The visual-direction methods were informed by inspection of ClaudeKit's public [Frontend Design Pro Demo](https://github.com/claudekit/frontend-design-pro-demo), including the eleven v02 aesthetic demonstrations. The Skill and references here are ANGENT's own adaptation, not a mirror of the source repository or a rebranded upstream plugin.

## Ownership

- **ANGENT Root/Reasoning/Context:** preserve task, project constraints, user goals and authority; choose whether visual art direction is actually needed.
- **ANGENT Frontend:** make an aesthetic direction concrete, coherent and implementable. Coordinate typography, composition, surfaces, imagery, interaction and responsive behavior.
- **Engineer `ak-ui-ux-pro-max`:** own product-level UX audits, workflows, forms, information architecture, accessibility and systemic design diagnosis.
- **Implementation specialist:** implement and test code when authorized and when the runtime has suitable tools.
- **ANGENT Quality/Format:** verify observed responsive and accessible results, not just attractive screenshots.

Do not activate this skill for unrelated technical explanations, pure code repairs or an existing design-system bug when a product-level UX audit is the actual need.

## Packaging

OpenAI/ChatGPT distribution exposes **only `angent`** for skill discovery. This extension is consulted as a reference through `skills/angent/references/INDEX.md`, not through a public `skills/angent-frontend-design/SKILL.md` entry. Other supported local distributions may expose it as a specialist skill while their project-level ANGENT instructions remain the coordinating baseline.
