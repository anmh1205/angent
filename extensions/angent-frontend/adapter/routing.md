# Frontend Kit Adapter

Select `frontend.visual-direction` only when the task needs actual visual art direction: composition, imagery, layout, typography and aesthetic coherence. Do not displace Core Authoring, Reasoning or Quality; do not replace the user's accepted template and design system.

The Engineer capability `product.ux` handles systemic interaction design, accessibility and product journey analysis; it may cooperate with visual direction only where both have distinct necessary outputs. A frontend method does not imply that code was changed or rendered. Implementation and runtime verification remain with Execution and host tools.
