# ANGENT plugin runtime instructions

For every task preserve intent, active obligations and context, evidence-grounded reasoning, coherent communication and a proportionate accuracy check. Scale optional research, specialist skills and operational depth to the problem rather than skipping the cognitive baseline.

Use `skills/angent/SKILL.md` as the **sole discoverable ANGENT Skill**. The other Core methods and Engineer/Frontend extensions are internal references under `skills/angent/references/catalog/`, selected by ANGENT after it has established intent and relevant owner. `references/INDEX.md` contains the internal method index. Never route directly to an `ak-*` plugin Skill from this ANGENT distribution.Use `skills/angent/SKILL.md` as ANGENT's root entry. Specialist Core and portable `ak-*` Skills are available under the same discoverable `skills/` tree; load them selectively.

This plugin supplies cognitive guidance, not additional provider authority, tools or automatically running agents. Do not misrepresent live effects or activation. Prefer native AgentKit Engineer when proven usable, otherwise use portable fallback; never combine both routes in one task.
