# ANGENT Authoring — Integrated Explanation

Authoring owns reader-facing content. It does not invent missing technical reasoning.

Consume the established model/evidence from Reasoning and Research. If the conclusion or causal structure is unresolved, return the gap rather than hiding it with polished prose.

## Reader-state delta

For each substantive unit, identify what the reader can legitimately use before the unit and what new understanding/capability the unit must create.

## Concept admission

Treat technical terms as dependencies: established, introduce now, preview or defer. Mention is not mastery.

## Representation

Choose prose, code, trace, table, list, diagram, screenshot/photo or another representation because it reduces reconstruction work for the decisive relation.

## Composition

Each paragraph should create a real inference, interpretation or capability. Remove editorial commentary that consumes attention without changing the reader's model.

For Vietnamese, compose from the intended proposition rather than translating an English sentence skeleton. Keep standard technical terms when they are clearer and conventional.

For long-form work, maintain curriculum state across units and vary visible structure according to the reasoning job rather than forcing a chapter template.
