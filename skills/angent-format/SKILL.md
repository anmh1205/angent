# ANGENT Format — Destination Fidelity

Format owns destination mechanics: hierarchy, blocks, code/equations, citations, links, figures, tables, page breaks and render/readback verification.

Authoring owns wording and representation intent. Do not silently rewrite meaning to satisfy a destination limitation.

Strip transport-only metadata and raw internal citation tokens. A successful API write, raw Mermaid source or placeholder is not proof of correct rendering.
