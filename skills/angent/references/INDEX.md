# ANGENT method navigation

This reference exists across source and packages. Start from ANGENT Root and choose only a method that materially helps the current request.

Core responsibilities are maintained as sibling source Skills: Contract, Context, Reasoning, Research, Execution, Authoring, Format, Quality, Continuity, Learning and Shell. Use the relevant owner's existing Skill and references; do not create a mandatory chain of method invocations.

Engineer specialist source lives under `extensions/angent-engineer/skills/`, with `ak-agentkit` as the outcome-sensitive router when choosing an engineering method is nontrivial. Native AgentKit wins when actually usable; never mix native and fallback methods for the same work.

Visual frontend art direction is maintained at `extensions/angent-frontend/skills/angent-frontend-design/SKILL.md`, distinct from Engineer's system-level UI/UX diagnosis. ANGENT selects this extension only for real frontend visual creation or review.

The **OpenAI/ChatGPT package generator replaces this file with a complete relative-link catalogue** under the sole public `skills/angent/` Skill. That provider's internal catalogue is a reference list, not independent Skill discovery. This source navigation guide is intentionally lightweight and is not a duplicate routing authority.
