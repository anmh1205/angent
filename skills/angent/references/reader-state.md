# Reader state — make each unit change what the reader can understand or do

Reader-facing material is complete when it creates the promised capability, not when it exhausts the subject.

## State

Distinguish:
- **established** — the reader can legitimately use the concept;
- **fragile** — previously learned but needs a compact repair for the current inference;
- **current gap** — the missing distinction, mechanism or capability;
- **target state** — what the reader should be able to explain, predict, diagnose, compare, implement or verify afterward.

Do not infer mastery from term occurrence.

## Active cognitive job

A section should normally resolve one meaningful question, mechanism, distinction, decision or procedure. The question can remain implicit in formal documents.

## Progression

Build new claims on established premises. If several unknown concepts are required simultaneously, establish a concrete anchor, split the conceptual step or defer unnecessary detail.

## Closure

Stop when the target state is reached at the promised depth. More correct facts are not automatically more useful.

For long-form work, preserve reader state across units instead of reconstructing a generic beginner in every chapter.
